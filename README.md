# เว็บไซต์ลงทะเบียน สนธยา4ทิศ

โปรเจกต์เว็บไซต์ภาษาไทยธีม Dark Fantasy สำหรับลงทะเบียนงาน **สนธยา4ทิศ** พร้อม API และฐานข้อมูล SQLite

## ข้อมูลงานที่ตั้งค่าไว้
- **วันจัดงาน:** 29 ตุลาคม 2569 (29 October 2026)
- **สถานที่:** มหาวิทยาลัยหอการค้าไทย อาคาร 23 ชั้น 7
- **กลุ่มผู้ลงทะเบียน:** บุคคลทั่วไป
- **ข้อมูลที่เก็บ:** ชื่อ-นามสกุล, ชื่อเล่น, เบอร์โทรศัพท์, อีเมล, ประเภทผู้ลงทะเบียน, คณะ, สถาบัน, รหัสนักศึกษา
- ผู้ลงทะเบียนเลือกประเภท (นักเรียน / นักศึกษา / อาจารย์ / บุคคลภายนอก) แล้วฟอร์มจะแสดงเฉพาะช่องที่เกี่ยวข้อง: นักศึกษา = คณะ+สถาบัน+รหัสนักศึกษา (บังคับ), อาจารย์ = คณะ+สถาบัน, นักเรียน = สถาบัน (รหัสไม่บังคับ), บุคคลภายนอก = ไม่ต้องกรอกช่องเหล่านี้ (แก้กติกาได้ที่ `TYPE_RULES` ใน `server.js` และ `public/app.js`)

## 1. ติดตั้งโปรแกรมที่จำเป็น
1. ดาวน์โหลดและติดตั้ง **Node.js รุ่น LTS** จาก https://nodejs.org/ เลือกตัวติดตั้งสำหรับ Windows แล้วติดตั้งตามขั้นตอน
2. หลังติดตั้ง เปิด Command Prompt หรือ PowerShell ใหม่
3. ตรวจสอบว่าติดตั้งสำเร็จด้วยคำสั่งต่อไปนี้:
   ```bash
   node -v
   npm -v
   ```
   ถ้าแสดงหมายเลขเวอร์ชัน แสดงว่าพร้อมใช้งาน

## 2. แตกไฟล์และติดตั้งโปรเจกต์
1. คลิกขวาไฟล์ ZIP แล้วเลือก **Extract All... / แตกไฟล์ทั้งหมด**
2. เปิดโฟลเดอร์ `sandhaya4thit` ที่แตกออกมา
3. คลิกแถบที่อยู่ของ File Explorer พิมพ์ `cmd` แล้วกด Enter เพื่อเปิด Command Prompt ในโฟลเดอร์นั้น (หรือเปิด Terminal ใน VS Code)
4. ติดตั้งแพ็กเกจที่จำเป็น:
   ```bash
   npm install
   ```
   รอจนเสร็จ ต้องมีการเชื่อมต่ออินเทอร์เน็ตในขั้นตอนนี้

## 3. ตั้งรหัสผ่านผู้ดูแล
ตั้งรหัสผ่านก่อนเปิดเว็บทุกครั้ง โดยเลือกคำสั่งตามโปรแกรมที่เปิดอยู่

**Windows Command Prompt (cmd):**
```bat
set ADMIN_PASSWORD=ใส่รหัสผ่านที่เดายากของคุณ
npm start
```

**Windows PowerShell:**
```powershell
$env:ADMIN_PASSWORD="ใส่รหัสผ่านที่เดายากของคุณ"
npm start
```

**macOS / Linux:**
```bash
export ADMIN_PASSWORD='ใส่รหัสผ่านที่เดายากของคุณ'
npm start
```

แทนข้อความตัวอย่างด้วยรหัสผ่านเฉพาะของผู้จัดงาน ห้ามส่งรหัสผ่านให้ผู้ลงทะเบียนหรือบันทึกไว้ในโค้ดหน้าเว็บ หน้าต่าง Terminal ต้องเปิดค้างไว้ขณะใช้งาน

## 4. เปิดเว็บไซต์
เมื่อ Terminal แสดงว่าเซิร์ฟเวอร์ทำงานแล้ว ให้เปิด Chrome หรือ Edge และไปที่:
- **หน้าลงทะเบียน:** http://localhost:3000
- **หน้าผู้ดูแล:** http://localhost:3000/admin.html
- **ตรวจสอบสถานะระบบ:** http://localhost:3000/api/health

กรอกข้อมูลทดลองแล้วกดปุ่มยืนยัน ข้อมูลจะถูกบันทึกลงไฟล์ `registrations.db` ภายในโฟลเดอร์โปรเจกต์โดยอัตโนมัติ อย่าลบไฟล์นี้หากต้องการเก็บรายชื่อที่ลงทะเบียนแล้ว

## 5. ดูและส่งออกรายชื่อ
1. เปิด `http://localhost:3000/admin.html`
2. ใส่รหัสผ่านเดียวกับ `ADMIN_PASSWORD` ที่ตั้งใน Terminal
3. กด **โหลดรายชื่อใหม่** เพื่อดูข้อมูลล่าสุด
4. กด **ดาวน์โหลด CSV** เพื่อส่งออกรายชื่อ เปิดด้วย Excel ได้ โดยไฟล์รองรับอักขระภาษาไทย

## 6. ปิดและเปิดเว็บใหม่
- หยุดเซิร์ฟเวอร์: กลับไปที่หน้าต่าง Terminal แล้วกด `Ctrl + C`
- เปิดใหม่: ตั้ง `ADMIN_PASSWORD` อีกครั้งในหน้าต่าง Terminal เดิม แล้วรัน `npm start`
- หากปิดหน้าต่าง Terminal เซิร์ฟเวอร์จะหยุดทำงาน แต่ข้อมูลที่บันทึกใน `registrations.db` จะยังอยู่

## 7. ภาษาไทยและฟอนต์
ไฟล์ HTML ใช้ `<meta charset="utf-8">` และ `lang="th"` อยู่แล้ว จึงรองรับข้อความภาษาไทย ส่วนฟอนต์ Kanit และ Prompt โหลดจาก Google Fonts หากไม่ได้เชื่อมต่ออินเทอร์เน็ต เว็บไซต์จะใช้ฟอนต์สำรองของระบบแทน หากภาษาไทยแสดงเป็นสี่เหลี่ยม ให้ติดตั้งฟอนต์ภาษาไทย/อัปเดต Windows และใช้ Chrome หรือ Edge รุ่นปัจจุบัน

## 8. ข้อควรทราบก่อนเปิดให้คนทั่วไปใช้จริง
- `localhost` ใช้ได้เฉพาะคอมพิวเตอร์ที่รันเซิร์ฟเวอร์ หากต้องการให้คนอื่นลงทะเบียนจากโทรศัพท์/อินเทอร์เน็ต ต้องนำเว็บไปติดตั้งบนโฮสต์ที่รองรับ Node.js และ HTTPS
- ตรวจสอบว่าโฮสต์เก็บไฟล์ฐานข้อมูลแบบถาวรและมีการสำรองข้อมูลเป็นประจำ
- หน้าเว็บเก็บข้อมูลส่วนบุคคล ควรแจ้งวัตถุประสงค์ ระยะเวลาจัดเก็บ และช่องทางติดต่อผู้จัดงานให้ชัดเจน จำกัดผู้เข้าถึงรายชื่อ และลบข้อมูลเมื่อหมดความจำเป็นตามนโยบายที่กำหนด
- เวอร์ชันนี้เป็นระบบพื้นฐานสำหรับงานขนาดเล็ก ก่อนใช้งานสาธารณะจริงควรทดสอบระบบและการสำรองข้อมูล

## จำกัดจำนวนต่อรอบ
- 1 รอบรับผู้เล่นได้สูงสุด 6 คน (`MAX_PER_ROUND`) ครบแล้วรอบนั้นจะกดเลือกไม่ได้ และเซิร์ฟเวอร์จะปฏิเสธการลงทะเบียนเพิ่มทันที
- ไม่มีช่องชื่อทีม ผู้เล่นที่เลือกรอบเดียวกันถือเป็นทีมเดียวกัน
- รายการรอบแก้ได้ที่ `rounds.json`
